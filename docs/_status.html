Update — 2026-08-08 · dependency security

Next.js upgraded to 16.3.0 35ba86c. The 16.2.x line carried 9 high-severity advisories: Server Actions DoS, cache confusion of response bodies, SSRF via rewrites, SSRF in Server Actions on custom servers, Image Optimization SVG DoS, unauthenticated disclosure of internal Server Function endpoints, unbounded Server Action payload on Edge, and a middleware/proxy bypass in App Router under Turbopack. npm audit now reports no Next advisories.

Build verified green before commit.

Not yet live. The commit is pushed, but Vercel Git integration is not connected for this project — Vercel cannot parse the git@github-personal:… SSH host alias used by every repo here. The running site serves the pre-upgrade build until someone runs npx vercel deploy --prod or connects the repo through the Vercel dashboard.

Known remaining advisories

Unrelated transitive advisories remain in some projects (brace-expansion, body-parser, @hono/node-server). These are dev-tooling dependencies unrelated to the Next CVEs and were deliberately left alone: npm audit fix across eight live projects in one unreviewed pass would churn lockfiles for little benefit. Worth a separate, deliberate look.
